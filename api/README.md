# Let's Start Coding Our AI Writing Tool

The AI Assistant Writer will propose three methods or ways of helping the user to write their content:
1. Draft and Edit
2. Agent
3. Deep Search

## 1. Draft and Edit
It is a cycle of writing and editing back and forth between the user and the wall until the final version.
In this case, the AI will correct spelling and try to augment some paragraphs.
When the user is happy with it, they can choose to publish the content.

## 2. Agent Edit
In this case, the user gives the Agent/Wall all the information necessary to do the job. The Agent will then iterate and propose a draft.
The latter could be validated or returned for a new version. It will go on until the user is satisfied.

## 3. Deep Search
In this last case, the user gives some prompts, draft, summary, or bibliography to the Wall. The Agent will then go deep to build the best possible write-up ever.
